# `ecos-time-tracking`

Модуль `ecos-time-tracking` позволяет вести учет времени, затраченного сотрудником на работу по конкретной задаче, документу непосредственно из карточки задачи, документа. Модуль реализован в виде аспекта, который может быть добавлен к типу данных.
