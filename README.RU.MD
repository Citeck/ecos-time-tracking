# Time tracking

Модуль `Time tracking` позволяет вести учет времени, затраченного сотрудником на работу по конкретной задаче, документу непосредственно из карточки задачи, документа. Модуль реализован в виде аспекта, который может быть добавлен к типу данных.

## Журнал по всем рабочим пространствам

Журнал `ecos-time-tracking-all-journal` показывает записи учёта времени из доступных рабочих пространств. Под колонкой «Затраченное время» отображается сумма по всем подходящим записям, включая другие страницы. Итог учитывает фильтры журнала и область рабочих пространств. В строках и сумме время отображается в часах, минутах и секундах без перевода часов в дни (например, 25h вместо 1d 1h).

По умолчанию по колонке «Дата начала» установлен период от месяца назад до текущего момента. Это относительный интервал, который сдвигается со временем. Пользователь может изменить или снять фильтр; сохранённые настройки журнала сохраняют собственные фильтры. Обычный журнал учёта времени не меняется.
